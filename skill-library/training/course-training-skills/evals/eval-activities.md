# Eval: Activities

**Skill:** `activity-designer`
**Case:** Session 1's Human Pattern-Recognition Game.

## Rubric
| Dimension | Pass criteria |
|---|---|
| Learning Objective Alignment | Activity's stated Objective traces to a real session objective; Debrief actually surfaces evidence of that objective |
| Audience/Level Appropriateness | Difficulty field matches stated level; no prerequisite knowledge assumed beyond what's taught so far |
| Consistency | Duration matches its agenda block; Materials/Participants fit declared `delivery.class_size`/`mode` |
| Artifact Quality | All required fields present (`README.md` §11) |

**Common failure mode to check for:** an activity that's fun but has no
real traceable purpose (`README.md` §38) — if the Debrief could be deleted
without losing anything, the activity likely fails this eval regardless of
how polished its other fields are.
