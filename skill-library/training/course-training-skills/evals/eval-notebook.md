# Eval: Notebook

**Skill:** `notebook-designer`
**Case:** Session 1's student + instructor notebooks.

## Rubric
| Dimension | Pass criteria |
|---|---|
| Correctness | Valid `nbformat` 4 JSON (`scripts/validate_course.py` — mechanical check) |
| Consistency | No concept/library used that isn't in this session's (or an earlier session's) Topics |
| Artifact Quality | Student notebook has no Solutions section; TODO cells are genuinely incomplete, not disguised working code |
| Adaptation Behavior | For a NO-notebook session (e.g. a system-design lecture), confirm the skill correctly declined rather than generating one anyway |
