# Eval: Assessment

**Skill:** `assessment-designer`
**Case:** Session 1's exit ticket + the final assessment.

## Rubric
| Dimension | Pass criteria |
|---|---|
| Learning Objective Alignment | Every item states an Objective it maps to; every course objective is covered by ≥1 item somewhere in the course |
| Correctness | No item tests a concept absent from Topics/Explanation up to that point |
| Artifact Quality | Evaluation Criteria are observable/specific, not "assess understanding" |
| Consistency | Format mix matches the course's stated Assessment Strategy |
