# Eval: Slides

**Skill:** `slide-designer`
**Case:** Session 1's slide specification (Stage 1).

## Rubric
| Dimension | Pass criteria |
|---|---|
| Correctness | Every slide's content traces to this session's actual Topics — not the course outline, not instructor notes copied verbatim |
| Artifact Quality | ≤6 bullets / ≤8 words per bullet as a default ceiling; Speaker Notes say something the slide doesn't already show |
| Consistency | Recap slide present; Instructions/Exercise slide present immediately before any Practice block |
| Adaptation Behavior | If no presentation/design capability is available, Stage 2 is explicitly skipped with the limitation stated — never a fabricated `.pptx` |
