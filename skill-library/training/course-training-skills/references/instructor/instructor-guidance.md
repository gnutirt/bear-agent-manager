# Instructor Guidance

Used by: `instructor-guide`.

## Required sections per session

`Teaching Focus, Explanation Guidance, Questions to Ask, Expected Answers,
Common Misconceptions, Common Difficulties, Intervention Strategies,
Fast-Finisher Activity, Recovery Strategy, Transitions, Session Recap`.

## Guidance for each section

- **Teaching Focus** — the 1–2 things that matter most if time runs short;
  what to protect if forced to cut.
- **Explanation Guidance** — how to explain the concept, not what it is
  (that's in `session-designer`'s Topics/Explanation) — analogies, common
  framing that works, order of exposition.
- **Questions to Ask** — real questions to pose during explanation, not
  rhetorical filler.
- **Expected Answers** — what a correct/partial/incorrect answer looks like,
  so the instructor can respond appropriately in the moment.
- **Common Misconceptions** — specific, not generic ("students often think
  a variable is a box that holds one type forever" beats "students may be
  confused").
- **Common Difficulties** — where learners at this level typically get stuck
  procedurally (syntax, tooling, setup) as distinct from conceptual
  misconceptions.
- **Intervention Strategies** — what to actually do when the above happen —
  a re-explanation angle, a smaller example, a pairing strategy.
- **Fast-Finisher Activity** — tied to the session's Extension Challenge if
  one exists; must not require material not yet taught.
- **Recovery Strategy** — what to cut/compress if running behind, stated
  concretely against the agenda's blocks.
- **Transitions** — the actual bridging language/action between agenda blocks.
- **Session Recap** — a short instructor-facing summary distinct from any
  learner-facing recap slide.

## Fidelity rule

Every field here must match the *actual* session — its real Topics, real
Agenda block names, and real Activities/Exercise. It is not a generic
teaching-tips document; it is specific to the session it accompanies
(`README.md` §16: "the instructor should be able to deliver the session
without redesigning it").
