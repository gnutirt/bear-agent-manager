# Presentation Style (Stage 2 input)

Fork and edit. This governs `slide-designer` Stage 2 (visual generation)
only — never instructional content, which lives in the slide spec (Stage 1).

## Typography
- Heading font: Cairo (700–800)
- Body font: IBM Plex Sans Arabic (400–600)
- Code font: JetBrains Mono

## Color System
- Primary (dark): #0F1F33 (navy) — title, activity, break and closing slides
- Secondary: #1F5FC9 (blue) — section dividers, accents, eyebrows
- Accent: #F0B44C (amber) — highlight pills, numbers on dark slides (dark text on it)
- Background: #F6F4EF (warm off-white), alternate #E9EEF5
- Text: #0F1F33 headings, #3D4A5C body

## Spacing & Layout
- Slide margin: 128px on a 1920×1080 canvas
- Default content alignment: right (Arabic / RTL decks); left for English decks

## Visual Density
- sparse — cards, big numbers and statements over bullets

## Diagram Style
- flat rounded cards, one accent color, numbered steps

## Code Block Style
- Theme: light, syntax-highlighted
- Font: JetBrains Mono

## Chart Style
- flat fills, no 3D, light gridlines

## Title Slide Style
- navy background, amber eyebrow (session number · format · duration), very
  large title, instructor name and date at the bottom

## Slide-type styles
- Section divider: blue background, huge amber section number, title, duration
- Activity slide: navy background, amber eyebrow "نشاط N · duration · grouping",
  3 numbered step cards, amber "outcome" pill at the bottom
- Trainer Intro: three full-width stacked cards, very large text — navy card
  (name), white card with blue border (professional title), amber card
  (instructor title); one icon per card, no paragraphs
- Contact: 2×2 grid of icon cards (LinkedIn highlighted), one call-to-action line
- Closing (Thank You): radial navy→blue gradient, decorative outline/filled
  circles, gradient-filled "Thank You" at display size, Arabic thanks line,
  instructor name and title underneath

## Footer
- course name · session number, bottom, 24px, muted

## Branding
- Logo placement: none
