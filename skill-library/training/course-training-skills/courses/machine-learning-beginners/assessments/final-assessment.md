# Final Assessment — Machine Learning Mini-Project (Session 6)

Format: project, summative, covers course objectives 1–6.

## Item: End-to-End Mini-Project
- **Objective:** Integrates all 6 course objectives — explaining ML,
  preparing data, training/evaluating a classifier, comparing approaches,
  applying scaling/tuning where relevant, and communicating results.
- **Format:** project + presentation
- **Instructions:** "Using the provided new dataset, prepare the data,
  split it correctly, train at least one classifier, evaluate it with
  appropriate metrics, and prepare a 3-minute summary covering your
  approach, your results, and one honest limitation of your work."
- **Expected Answer/Result:** A working notebook or script showing data
  prep → split → train → evaluate, plus a spoken/written 3-minute summary.
- **Evaluation Criteria:**
  | Criterion | Meets expectation |
  |---|---|
  | Data preparation | Missing values/dtypes handled appropriately |
  | Correct split | Train/test split performed before any model fitting |
  | Model training | At least one classifier trained without errors |
  | Evaluation | Uses accuracy and/or confusion matrix/precision/recall correctly, matching the dataset's nature |
  | Justification | Can explain, in plain language, why their choices (model, scaling) fit this dataset |
  | Limitation | Names at least one honest limitation (e.g. small dataset, class imbalance, no tuning done) rather than overclaiming |

Not scored on: achieving a specific accuracy threshold — the objective is
correct process and honest communication, consistent with the course's
formative-first assessment strategy (`course-plan.md`).
