# Assessment: Session 1 Exit Ticket

Format: 5-question knowledge check, ungraded/formative, last 5 minutes of session.

## Item 1
- **Objective:** Session Objective 1 (ML vs. traditional programming)
- **Format:** short-answer
- **Instructions:** "In one sentence, what's the difference between traditional programming and machine learning?"
- **Expected Answer/Result:** Mentions that traditional programming follows
  explicit human-written rules, while ML learns patterns from example data.
- **Evaluation Criteria:** Present if the answer identifies "rules written by
  a human" vs. "learned from data/examples" — exact wording not required.

## Item 2
- **Objective:** Session Objective 2 (types of ML)
- **Format:** MCQ
- **Instructions:** "Grouping customers into segments with no predefined
  categories is an example of: (a) supervised learning (b) unsupervised
  learning (c) reinforcement learning"
- **Expected Answer/Result:** (b) unsupervised learning
- **Evaluation Criteria:** Correct/incorrect.

## Item 3
- **Objective:** Session Objective 2 (types of ML)
- **Format:** MCQ
- **Instructions:** "Predicting house price from square footage, using
  historical sales with known prices, is an example of: (a) supervised
  learning (b) unsupervised learning (c) reinforcement learning"
- **Expected Answer/Result:** (a) supervised learning
- **Evaluation Criteria:** Correct/incorrect.

## Item 4
- **Objective:** Session Objective 3 (ML workflow)
- **Format:** short-answer
- **Instructions:** "List the 4 steps of the standard ML workflow, in order."
- **Expected Answer/Result:** Collect/Prepare Data → Train a Model →
  Evaluate → Use.
- **Evaluation Criteria:** All 4 steps present, correct order; minor wording
  variation accepted.

## Item 5
- **Objective:** Session Objective 4 (environment setup)
- **Format:** exit-ticket
- **Instructions:** "Did your smoke-test notebook run successfully and show
  a dataset shape of (150, 4)? If not, what error did you see?"
- **Expected Answer/Result:** Yes/No + error message if no.
- **Evaluation Criteria:** Used by the instructor to identify who needs
  setup help before Session 2, not graded.
