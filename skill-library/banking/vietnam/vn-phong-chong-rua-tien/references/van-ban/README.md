# Văn bản gốc

Đặt ở đây bản đầy đủ (txt, md hoặc pdf) của các văn bản đang áp dụng, đặt tên theo số hiệu, ví dụ:

- `luat-14-2022-QH15.md`
- `nghi-dinh-19-2023-ND-CP.md`
- `thong-tu-09-2023-TT-NHNN.md`

Skill chỉ trích điều khoản, ngưỡng tiền, thời hạn có trong các file này. Khi văn bản được sửa đổi, thay file và ghi ngày cập nhật ở đầu file.
