# Văn bản gốc

Đặt ở đây bản đầy đủ (txt, md hoặc pdf) của các văn bản đang áp dụng, đặt tên theo số hiệu, ví dụ:

- `thong-tu-31-2024-TT-NHNN.md` (phân loại tài sản có, hiệu lực 01/07/2024)
- `thong-tu-37-2025-TT-NHNN.md` (sửa đổi Thông tư 31/2024)
- văn bản hiện hành về trích lập dự phòng rủi ro

Nếu cần phân loại cho kỳ trước 01/07/2024, thêm `thong-tu-11-2021-TT-NHNN.md`.
Skill chỉ dùng số ngày, tỷ lệ, số điều có trong các file này. Khi văn bản được sửa đổi, thay file và ghi ngày cập nhật ở đầu file.
