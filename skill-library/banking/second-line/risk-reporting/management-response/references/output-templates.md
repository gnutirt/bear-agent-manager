# Output templates

## Obligation map

| Field | Content |
|---|---|
| Obligation ID | Stable ID |
| Source | Regulator, rule, guidance, section, date, URL if public |
| Requirement | Concise requirement summary |
| Applicability | Institution, product, activity, geography, thresholds |
| Impacted process | Process or control area |
| Control objective | What must be true |
| Evidence | Records needed to prove operation |
| Owner | Role, not person |
| Status | draft, in-review, approved, not-applicable, open-question |
| Open questions | Items requiring legal/compliance review |

## Control test workpaper

1. Scope and control objective
2. Source criteria
3. Population and sample
4. Test procedure
5. Evidence inspected
6. Results
7. Exceptions and severity rationale
8. Issue write-up if needed
9. Reviewer questions

## Executive risk pack

1. Decision required
2. Top risk movements
3. Red/amber items and owner actions
4. Emerging regulatory change
5. Evidence confidence and data quality notes
6. Items requiring committee escalation
