# Văn bản gốc

Đặt ở đây bản đầy đủ (txt, md hoặc pdf) của các văn bản đang áp dụng, đặt tên theo số hiệu, ví dụ:

- `nghi-dinh-135-2024-ND-CP.md` (điện mặt trời mái nhà tự sản xuất, tự tiêu thụ; ban hành 22/10/2024)
- văn bản sửa đổi, bổ sung hoặc thay thế (nếu có)
- quy định kỹ thuật đấu nối, đo đếm của Bộ Công Thương/EVN mà dự án phải theo

Skill chỉ trích ngưỡng, thủ tục, số điều có trong các file này. Khi văn bản được sửa đổi, thay file và ghi ngày cập nhật ở đầu file.
